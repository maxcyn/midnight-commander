  • 3. Set .env Keys — Connect Sentry, CREAO & Photon SIP.
  • 4. npm run configure:voice — Auto-builds phone agent tools.
why manifest probes beat logs alone surface symptom ≠ root cause

How live probes separate symptoms from root causes

Outage Type Sentry Logs Live Probes Action Taken
Feature Outage Recs 504 timeout Payments 60ms Disable recs flag
Shared Pool Slow Recs 504 timeout Payments 1800ms Switch payment provider
Hard Payment Down Payment 502 error Payments failing Escalate (no auto-fix)
why independent probes matter shared pools & queues

A slow payment provider saturates the shared connection pool and makes recommendations time out first. Live probes catch the 1800ms payment lag that logs miss.

Takeaway: Any service with health endpoints and safe mitigation hooks can plug into SecondShift in minutes. zero hardcoded service logic

Check Rule If Failed
1. Evidence Evidence is fresh (<15m) and proves one single cause. escalate
2. Manifest Proposed fix is allowed for that cause in your manifest. escalate
3. Re-probe Re-tests live dependency health right before acting. blocked
4. Lock Approval is under 10m old and hasn't run yet. no-op

06 // how the system learns database + incidents.md + runbooks

Turning human decisions into memory

  • Snapshot every decision — Saves live probe latencies on Approve or Decline.
  • Auto-detect manual fixes — Polls /config to see what the engineer changed.
  • Sync incidents.md — Logs symptom, probe snapshot & verified fix.
  • Draft & test runbooks — Evaluates against 12 fixed & held-out refusal cases.
Safety rule: Past memory guides the next diagnosis, but never skips live safety checks. verified before closing
